title: Jerk Chicken with Coconut Rice & Kidney Beans
slot: dinner

tags: []

macros: { protein_g: 53, kcal: 730 }
ingredients:
  - { ingredient: chicken-thighs, qty: 3, unit: each, note: "skinless, bone out" }
  - { ingredient: jerk-seasoning, qty: 20, unit: g }
  - { ingredient: lime, qty: 1, unit: each }
  - { ingredient: brown-rice, qty: 150, unit: g, note: raw }
  - { ingredient: kidney-beans, qty: 200, unit: g, prep: drained }
  - { ingredient: coconut-milk, qty: 100, unit: ml }
  - { ingredient: spring-onion, qty: 2, unit: each, prep: sliced }
  - { ingredient: spinach, qty: 100, unit: g }
  - { ingredient: salt, qty: 1, unit: pinch }
---

1. Rub the chicken thighs with the jerk seasoning and a squeeze of lime juice. Marinate for at least 15 minutes.
2. Add the rice, kidney beans, coconut milk, and a splash of water into the rice cooker. Run on a standard cycle until the rice is tender.
3. Air fry the chicken thighs at 200°C for 15–18 minutes, turning once, until charred at the edges and cooked through.
4. Wilt the spinach and sliced spring onion in a hot skillet for 2 minutes.
5. Serve the jerk chicken over the coconut rice and kidney beans, with the wilted spinach and remaining lime wedges alongside.
