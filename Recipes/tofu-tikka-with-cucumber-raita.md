---
title: Tofu Tikka with Cucumber Raita
slot: lunch
protein: tofu
effort: medium
tags: []
appliances: [air-fryer]
macros: { protein_g: 44, kcal: 415 }
ingredients:
  - { ingredient: tofu, qty: 2, unit: pack, prep: "patted dry, cut into 3cm cubes" }
  - { ingredient: tikka-paste, qty: 30, unit: g, note: about 2 tbsp }
  - { ingredient: greek-yogurt, qty: 150, unit: g }
  - { ingredient: cucumber, qty: 0.5, unit: each, prep: grated, note: squeezed of excess water }
  - { ingredient: lemon, qty: 0.5, unit: each, prep: juiced }
  - { ingredient: rocket, qty: 60, unit: g }
---

1. Mix the tikka paste with 50g of the yogurt and toss the tofu in it until coated.
2. Air-fry at 200°C for 12–15 minutes, shaking halfway, until charred at the edges.
3. Meanwhile, stir the cucumber and lemon juice into the rest of the yogurt with a pinch of salt. Serve the tofu on the rocket with the raita alongside.
