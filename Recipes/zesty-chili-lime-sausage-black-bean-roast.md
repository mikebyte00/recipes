title: Zesty Chili-Lime Sausage & Black Bean Roast
slot: breakfast
protein: sausage
effort: medium
tags: []
appliances: [air-fryer]
macros: { protein_g: 29, kcal: 370 }
ingredients:
  - { ingredient: vegetarian-sausage, qty: 4, unit: each, prep: sliced into chunks }
  - { ingredient: black-beans, qty: 1, unit: can, prep: "drained, patted dry" }
  - { ingredient: chili-powder, qty: 1, unit: tsp }
  - { ingredient: cottage-cheese, qty: 160, unit: g }
  - { ingredient: lime, qty: 1, unit: each }
  - { ingredient: oil-spray, note: light spray }
---

1. Mix the sausage chunks and black beans with oil spray and chili powder.
2. Transfer to the air fryer basket and air fry at 200°C for 10–12 minutes, shaking halfway, until everything is well roasted and crispy.
3. **To Serve:** Spoon over cottage cheese and squeeze fresh lime juice over the top.
