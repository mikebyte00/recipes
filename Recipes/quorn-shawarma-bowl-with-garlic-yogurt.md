---
title: Quorn Shawarma Bowl with Garlic Yogurt
slot: lunch
protein: quorn
effort: medium
tags: []
appliances: [air-fryer]
macros: { protein_g: 38, kcal: 365 }
ingredients:
  - { ingredient: quorn-pieces, qty: 300, unit: g }
  - { ingredient: shawarma-spice, qty: 2, unit: tsp }
  - { ingredient: chickpeas, qty: 1, unit: can, prep: "drained and rinsed" }
  - { ingredient: greek-yogurt, qty: 150, unit: g }
  - { ingredient: garlic, qty: 1, unit: clove, prep: finely grated }
  - { ingredient: cucumber, qty: 0.5, unit: each, prep: diced }
  - { ingredient: cherry-tomatoes, qty: 150, unit: g, prep: halved }
---

1. Toss the Quorn pieces and chickpeas with the shawarma spice and a splash of water, then air-fry at 200°C for 10–12 minutes, shaking halfway, until the Quorn is golden and the chickpeas are starting to crisp.
2. Meanwhile, stir the garlic into the yogurt with a pinch of salt.
3. Pile the cucumber and tomatoes into bowls, top with the Quorn and chickpeas, and spoon over the garlic yogurt.
