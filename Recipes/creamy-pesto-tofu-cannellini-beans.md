tags: []

macros: { protein_g: 48, kcal: 410 }
ingredients:
  - { ingredient: tofu, qty: 1, unit: pack, prep: pressed and diced }
  - { ingredient: cannellini-beans, qty: 400, unit: g, prep: drained }
  - { ingredient: cherry-tomatoes, qty: 150, unit: g, prep: halved }
  - { ingredient: green-pesto, qty: 30, unit: g }
  - { ingredient: cottage-cheese, qty: 120, unit: g }
  - { ingredient: olive-oil }
---

1. Dice the tofu and fry in a hot skillet with olive oil for 5–6 minutes until golden on all sides.
2. Pour in the drained cannellini beans, halved cherry tomatoes, and green pesto.
3. Toss for 2 minutes until hot, then remove from the heat and stir in the cottage cheese for a rich, velvety sauce.
