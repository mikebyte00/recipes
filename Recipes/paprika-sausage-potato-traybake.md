  - { ingredient: pork-sausages, qty: 4, unit: each, note: "free range, from Soutars" }
  - { ingredient: maris-piper-potatoes, qty: 400, unit: g, prep: cut into roughly 4cm chunks }
  - { ingredient: onion, qty: 0.5, unit: each, prep: sliced }
  - { ingredient: baby-leaf-greens, qty: 100, unit: g, prep: thick stems discarded, note: half a 200g pack }
  - { ingredient: garlic, qty: 1, unit: clove, prep: crushed }
  - { ingredient: smoked-paprika, qty: 5, unit: g, note: "2 tsp, sweet smoked" }
  - { ingredient: honey, qty: 3, unit: g, note: "½ tsp, clear" }
  - { ingredient: white-wine-vinegar, qty: 0.5, unit: tbsp }
  - { ingredient: olive-oil, qty: 20, unit: g, note: "1½ tbsp: 1 with the potatoes, ½ for the paprika oil" }
  - { ingredient: salt, note: ¼ tsp }
---

1. Heat the oven to 220°C (200°C fan). Line a roasting tin with baking parchment. Add the potatoes, onion, salt and 1 tbsp of the oil, toss together and roast for 15 minutes. Meanwhile, in a small bowl mix the remaining ½ tbsp oil, the paprika, honey, vinegar and garlic.
2. After 15 minutes, stir the potatoes and nestle in the sausages. Roast for another 15 minutes. Meanwhile, roughly slice the greens.
3. Push the sausages to one side, stir the greens through the potatoes, then turn the sausages and put them back on top. Pour the paprika oil over everything, season and roast for another 15–18 minutes, until the sausages are golden with no pink meat remaining and the potatoes are tender.
