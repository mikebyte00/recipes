ingredients:
  - { ingredient: chicken-breast, qty: 2, unit: each, prep: cut into strips }
  - { ingredient: red-pepper, qty: 2, unit: each, prep: sliced }
  - { ingredient: red-onion, qty: 1, unit: each, prep: sliced }
  - { ingredient: fajita-seasoning, qty: 15, unit: g, note: about 2 tbsp }
  - { ingredient: olive-oil, qty: 10, unit: g }
  - { ingredient: wholemeal-wraps, qty: 4, unit: each }
  - { ingredient: greek-yogurt, qty: 100, unit: g }
  - { ingredient: lime, qty: 1, unit: each }
  - { ingredient: cheddar, qty: 40, unit: g, prep: grated }
---

1. Heat the oven to 200°C fan. Toss the chicken, pepper and onion in a roasting tin with the oil, the fajita seasoning and the juice of half the lime.
2. Spread everything out in one layer and roast for 20–25 minutes, stirring halfway, until the chicken is cooked through and the veg is charred at the edges.
3. For the last 3 minutes, wrap the tortillas in foil and warm them in the oven. Cut the other lime half into wedges.
4. Fill the wraps with the chicken and veg, the cheddar and a spoonful of yogurt, with the lime wedges to squeeze over.
