---
title: Air-Fried Cocoa Peanut Butter Oat Bars
slot: breakfast
protein: protein-powder
effort: medium
tags: [eat-cold]
appliances: [air-fryer]
macros: { protein_g: 30, kcal: 420 }
ingredients:
  - { ingredient: rolled-oats, qty: 100, unit: g }
  - { ingredient: cocoa-powder, qty: 20, unit: g }
  - { ingredient: vegan-protein-powder, qty: 40, unit: g, note: vanilla }
  - { ingredient: peanut-butter, qty: 35, unit: g }
  - { ingredient: oat-milk, qty: 100, unit: ml }
  - { ingredient: salt, qty: 1, unit: pinch }
---

1. Whisk the rolled oats, cocoa powder, vegan protein powder and salt together in a bowl.
2. Stir in the peanut butter, oat milk and a splash of water, mixing until it forms one thick, homogenous batter.
3. Press evenly into a small parchment-lined tin that fits your air fryer basket.
4. Air fry at 180°C for 18–20 minutes, until set but still a little soft in the centre.
5. Cool in the tin for 20 minutes until firm, then cut into 4 bars.
