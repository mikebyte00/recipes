  - { ingredient: chicken-breast, qty: 2, unit: each }
  - { ingredient: brown-rice, qty: 150, unit: g, note: raw }
  - { ingredient: hoisin-sauce, qty: 60, unit: g }
  - { ingredient: soy-sauce, qty: 15, unit: g }
  - { ingredient: rice-vinegar, qty: 20, unit: ml }
  - { ingredient: sesame-seeds, qty: 2, unit: tbsp }
  - { ingredient: spring-onion, qty: 4, unit: each, prep: finely sliced }
  - { ingredient: cucumber, qty: 0.5, unit: each, prep: cut into thin batons }
---

1. Add the brown rice and water to the rice cooker and run a standard cycle.
2. Air-fry the chicken breasts at 200°C for 10 minutes.
3. Mix the cooked rice with the soy sauce, half the rice vinegar and most of the sesame seeds. Turn the chicken, pat the rice into a layer beside it in the basket, and air-fry for a further 8–10 minutes until the chicken is cooked through and the rice is crisp.
4. Loosen the hoisin sauce with the remaining rice vinegar and toss the hot chicken in it.
5. Serve the chicken on the crispy rice with the cucumber, spring onion and the last of the sesame seeds.
