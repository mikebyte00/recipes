ingredients:
  - { ingredient: quorn-pieces, qty: 300, unit: g, prep: chopped small }
  - { ingredient: edamame, qty: 200, unit: g, note: frozen }
  - { ingredient: soy-sauce, qty: 20, unit: g }
  - { ingredient: lime, qty: 1, unit: each }
  - { ingredient: red-chilli, qty: 1, unit: each, prep: finely chopped }
  - { ingredient: spring-onion, qty: 3, unit: each, prep: finely sliced }
  - { ingredient: lettuce, qty: 180, unit: g, prep: leaves separated into cups, note: two little gems }
---

1. Fry the Quorn and edamame in a hot skillet with a splash of water for 5–6 minutes, until the Quorn is lightly browned and the edamame is hot.
2. Take it off the heat and stir in the soy sauce, the juice of the lime, the chilli and most of the spring onion.
3. Spoon into the lettuce cups and scatter with the rest of the spring onion.
