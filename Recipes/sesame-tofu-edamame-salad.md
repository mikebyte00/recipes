macros: { protein_g: 44, kcal: 420 }
ingredients:
  - { ingredient: tofu, qty: 2, unit: pack, prep: "patted dry, cut into 2cm cubes" }
  - { ingredient: edamame, qty: 150, unit: g, note: "frozen, defrosted" }
  - { ingredient: cucumber, qty: 0.5, unit: each, prep: diced }
  - { ingredient: spring-onion, qty: 2, unit: each, prep: finely sliced }
  - { ingredient: soy-sauce, qty: 25, unit: g }
  - { ingredient: sesame-oil, qty: 5, unit: g }
---

1. Toss the tofu with half the soy sauce and air-fry at 200°C for 12–15 minutes, shaking halfway, until golden and crisp at the edges.
2. Mix the rest of the soy sauce with the sesame oil.
3. Toss the warm tofu with the edamame, cucumber, spring onion and the dressing. Eat warm, or keep it in the fridge and eat it cold the next day.
