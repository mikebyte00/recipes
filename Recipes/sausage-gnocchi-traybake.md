ingredients:
  - { ingredient: pork-sausages, qty: 4, unit: each, note: "free range, from Soutars" }
  - { ingredient: gnocchi, qty: 300, unit: g, note: "shop-bought, straight from the pack" }
  - { ingredient: red-pepper, qty: 2, unit: each, prep: cut into chunks }
  - { ingredient: red-onion, qty: 1, unit: each, prep: cut into wedges }
  - { ingredient: cherry-tomatoes, qty: 200, unit: g }
  - { ingredient: olive-oil, qty: 10, unit: g }
  - { ingredient: dried-oregano, note: 1 tsp }
  - { ingredient: mozzarella, qty: 125, unit: g, prep: torn, note: one ball }
  - { ingredient: salt }
  - { ingredient: black-pepper }
---

1. Heat the oven to 200°C fan. Toss the gnocchi, pepper and onion in a roasting tin with the oil, oregano and some salt and pepper. Nestle in the sausages and roast for 20 minutes.
2. Turn the sausages, stir the gnocchi and add the tomatoes. Roast for another 10–15 minutes, until the sausages are golden with no pink remaining and the gnocchi is crisp.
3. Tear the mozzarella over the top and return the tin to the oven for 5 minutes, until melted.
