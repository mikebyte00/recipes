ingredients:
  - { ingredient: chicken-thighs, qty: 3, unit: each, note: "skin on, trimmed of excess fat, bone out" }
  - { ingredient: chilli-oil, qty: 5, unit: g, note: "Chiu Chow-style" }
  - { ingredient: marmalade, qty: 50, unit: g, note: "Seville orange" }
  - { ingredient: soy-sauce, qty: 25, unit: g }
  - { ingredient: rice-vinegar, qty: 10, unit: ml }
  - { ingredient: brown-rice, qty: 150, unit: g, note: raw }
  - { ingredient: sweetheart-cabbage, qty: 200, unit: g, prep: "cut into wedges" }
  - { ingredient: salt, qty: 1, unit: pinch }
---

1. Whisk together the chilli oil, marmalade, soy sauce and rice vinegar. Toss the chicken thighs, skin-side up, in half the sauce.
2. Air fry the chicken at 200°C for 20–22 minutes, basting with the remaining sauce halfway through, until sticky and cooked through.
3. Meanwhile, add the brown rice, a pinch of salt and water into the rice cooker. Run a standard cycle until tender.
4. In the last few minutes, toss the cabbage wedges in a hot skillet for 2–3 minutes until just wilted.
5. Serve the chicken over the rice with the wilted cabbage, spooning over any sticky juices from the air fryer.
