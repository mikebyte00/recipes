ingredients:
  - { ingredient: chicken-breast, qty: 2, unit: each, prep: diced }
  - { ingredient: egg-whites, qty: 150, unit: g, note: "50g to coat the chicken, 100g for the rice" }
  - { ingredient: eggs, qty: 2, unit: each }
  - { ingredient: cornflour, qty: 30, unit: g, note: "20g to coat the chicken, 10g to thicken the sauce" }
  - { ingredient: basmati-rice, qty: 100, unit: g, note: "cooked — a pouch or leftovers" }
  - { ingredient: cauliflower-rice, qty: 200, unit: g }
  - { ingredient: red-pepper, qty: 1, unit: each, prep: chunked }
  - { ingredient: tenderstem-broccoli, qty: 200, unit: g }
  - { ingredient: pineapple, qty: 200, unit: g, note: "tinned chunks, drained — keep the juice" }
  - { ingredient: soy-sauce, qty: 20, unit: g, note: light }
  - { ingredient: honey, qty: 10, unit: g }
  - { ingredient: sesame-seeds, qty: 1, unit: tbsp }
---

1. Toss the diced chicken in 50g of the egg whites, then in 20g of the cornflour. Air fry at 200°C for 12–14 minutes, shaking halfway, until crisp and cooked through.
2. Meanwhile, stir-fry the pepper and broccoli in a hot skillet for 4–5 minutes, adding the pineapple for the last minute. Tip onto a plate.
3. Add the basmati and cauliflower rice to the same skillet for 3–4 minutes. Push to one side, scramble the eggs and remaining egg whites, then stir it all together. Divide between two bowls.
4. Whisk the soy sauce, honey, a splash of pineapple juice and the remaining cornflour with a little water. Bubble it in the skillet until glossy, then toss the chicken and veg through.
5. Spoon over the egg-fried rice and finish with the sesame seeds.
