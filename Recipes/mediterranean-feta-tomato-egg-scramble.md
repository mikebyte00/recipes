ingredients:
  - { ingredient: feta, qty: 60, unit: g, prep: crumbled, note: lighter }
  - { ingredient: eggs, qty: 4, unit: each }
  - { ingredient: cherry-tomatoes, qty: 150, unit: g, prep: halved }
  - { ingredient: spinach, qty: 100, unit: g }
  - { ingredient: sourdough, qty: 2, unit: slices, note: seeded }
  - { ingredient: olive-oil }
---

1. Toast your sourdough.
2. Whisk the eggs in a bowl.
3. Sauté the cherry tomatoes in a skillet for 2 minutes until softened, then add the spinach until wilted.
4. Pour over the whisked eggs and scramble gently. Just before taking off the heat, fold through the crumbled feta so it melts slightly, then pile high onto the toast.
