ingredients:
  - { ingredient: chicken-thighs, qty: 4, unit: each, note: "skinless, bone out" }
  - { ingredient: baby-potatoes, qty: 400, unit: g, prep: halved }
  - { ingredient: red-onion, qty: 1, unit: each, prep: cut into wedges }
  - { ingredient: cherry-tomatoes, qty: 200, unit: g }
  - { ingredient: lemon, qty: 1, unit: each }
  - { ingredient: garlic, qty: 3, unit: clove, prep: crushed }
  - { ingredient: dried-oregano, note: 2 tsp }
  - { ingredient: olive-oil, qty: 15, unit: g }
  - { ingredient: feta, qty: 60, unit: g, prep: crumbled }
  - { ingredient: salt }
  - { ingredient: black-pepper }
---

1. Heat the oven to 200°C fan. Toss the potatoes and onion in a roasting tin with half the oil and a pinch of salt, and roast for 20 minutes.
2. Meanwhile, mix the rest of the oil with the oregano, garlic, the zest of the lemon and the juice of half of it, then season and turn the chicken thighs in it.
3. Add the chicken and tomatoes to the tin, spoon over any marinade left in the bowl and tuck in the squeezed lemon half. Roast for 25 minutes, until the chicken is cooked through and the potatoes are golden.
4. Crumble over the feta and serve with the other lemon half cut into wedges.
