---
title: Moroccan Spiced Chicken with Air-Fried Butternut Squash & Flaked Almonds
slot: dinner
protein: chicken
effort: low
tags: []
appliances: [air-fryer]
macros: { protein_g: 48, kcal: 730 }
ingredients:
  - { ingredient: chicken-thighs, qty: 4, unit: each, note: "skin on, bone out" }
  - { ingredient: butternut-squash, qty: 450, unit: g, prep: diced }
  - { ingredient: courgette, qty: 150, unit: g, prep: sliced into half-moons }
  - { ingredient: ras-el-hanout, qty: 15, unit: g }
  - { ingredient: flaked-almonds, qty: 15, unit: g }
  - { ingredient: olive-oil }
  - { ingredient: salt, qty: 1, unit: pinch }
---

1. Toss the butternut squash cubes and sliced courgette in a bowl with olive oil, salt, and half the Moroccan spice blend. Air fry at 200°C for 10 minutes.
2. Rub the remaining spice blend onto the chicken thighs. Add them to the air fryer alongside the veg and cook both together for 10 more minutes, scattering the flaked almonds in over the veg for the final 2 minutes to toast.
3. Remove the veg as the squash base and set aside. Finish the chicken with 4 minutes on max crisp while you plate.
4. Pour the resting chicken juices over the plate for moisture. Serve chicken over the squash base.
