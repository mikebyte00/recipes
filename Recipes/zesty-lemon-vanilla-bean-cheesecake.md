title: Zesty Lemon & Vanilla Bean "Cheesecake"
slot: pudding
effort: low
tags: []
appliances: []
macros: { protein_g: 11, kcal: 120 }
ingredients:
  - { ingredient: greek-yogurt, qty: 200, unit: g, note: Fage 2% }
  - { ingredient: honey, qty: 12, unit: g }
  - { ingredient: raspberries, qty: 80, unit: g }
  - { ingredient: lemon, qty: 0.5, unit: each, prep: juiced and zested }
  - { ingredient: vanilla-extract, qty: 2, unit: g }
---

1. Whisk the Fage 2%, honey, and vanilla extract until very smooth.
2. Stir in the lemon juice and half of the lemon zest. The acidity will naturally thicken the Greek yogurt.
3. Divide into bowls and top with raspberries and the remaining lemon zest.
4. Chill for 20 minutes before serving.
