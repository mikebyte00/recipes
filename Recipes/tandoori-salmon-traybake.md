---
title: Tandoori Salmon Traybake
slot: dinner
protein: oily-fish
effort: high
tags: []
appliances: [oven]
macros: { protein_g: 50, kcal: 650 }
ingredients:
  - { ingredient: salmon, qty: 2, unit: fillets, note: skin on }
  - { ingredient: tandoori-paste, qty: 30, unit: g, note: about 2 tbsp }
  - { ingredient: greek-yogurt, qty: 150, unit: g }
  - { ingredient: cauliflower, qty: 1, unit: each, prep: cut into small florets, note: small }
  - { ingredient: chickpeas, qty: 1, unit: can, prep: "drained and rinsed" }
  - { ingredient: red-onion, qty: 1, unit: each, prep: cut into wedges }
  - { ingredient: spinach, qty: 100, unit: g }
  - { ingredient: olive-oil, qty: 10, unit: g }
  - { ingredient: lemon, qty: 1, unit: each }
  - { ingredient: salt }
---

1. Heat the oven to 200°C fan. Mix two-thirds of the tandoori paste with 50g of the yogurt and spread it over the flesh side of the salmon. Set aside.
2. Toss the cauliflower, chickpeas and onion in a roasting tin with the oil, the rest of the paste and a pinch of salt, and roast for 20 minutes.
3. Give the tin a stir and sit the salmon on top, skin-side down. Roast for 12–15 minutes, until the salmon flakes easily.
4. Lift out the salmon and stir the spinach through the hot tin until it wilts. Mix the rest of the yogurt with the lemon juice and a pinch of salt, and serve it drizzled over. The skin lifts off on the plate if you'd rather not eat it.
