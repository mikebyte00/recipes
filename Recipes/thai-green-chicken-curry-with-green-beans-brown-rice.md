ingredients:
  - { ingredient: chicken-thighs, qty: 4, unit: each, note: "skinless, bone out", prep: sliced into strips }
  - { ingredient: thai-green-curry-paste, qty: 154, unit: g, note: "Ice Kitchen Thai green curry paste, 2 × 77 g packs" }
  - { ingredient: coconut-milk, qty: 250, unit: ml }
  - { ingredient: brown-rice, qty: 100, unit: g, note: raw }
  - { ingredient: green-beans, qty: 150, unit: g, prep: halved }
  - { ingredient: spinach, qty: 100, unit: g }
  - { ingredient: lime, qty: 1, unit: each }
  - { ingredient: salt, qty: 1, unit: pinch }
---

1. Add the rice, a pinch of salt, and water (1:2 ratio) into the rice cooker and let it run.
2. Brown the chicken strips in a hot skillet for 5–6 minutes.
3. Stir in both packs of Ice Kitchen paste for a minute until fragrant, then pour in the coconut milk and add the green beans. Simmer for 8–10 minutes until the chicken is cooked through and the sauce has thickened.
4. Stir the spinach through until it wilts, squeeze in half the lime, and serve over the rice with the remaining lime in wedges.
