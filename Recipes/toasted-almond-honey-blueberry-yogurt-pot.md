  - { ingredient: greek-yogurt, qty: 200, unit: g, note: Fage 2% }
  - { ingredient: blueberries, qty: 100, unit: g }
  - { ingredient: flaked-almonds, qty: 15, unit: g }
  - { ingredient: honey, qty: 10, unit: g }
  - { ingredient: vanilla-extract, qty: 2, unit: g }
---

1. Whisk the Greek yogurt with the honey and vanilla extract until smooth.
2. Fold in three-quarters of the blueberries, lightly crushing a few as you go to ripple the mixture.
3. Divide between two bowls and top with the remaining blueberries.
4. Scatter with flaked almonds just before serving.
