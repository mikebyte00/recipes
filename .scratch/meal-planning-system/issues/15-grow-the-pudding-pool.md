# Grow The Pudding Pool

Type: task
Status: open
Blocked by: —

## Question

Write ~3 more pudding Recipes.

[Complete The Weekly Layout](14-complete-the-weekly-layout.md) made pudding
nightly, so each Menu now needs **7 pudding Slots filled from a pool of 4**.
Repeats are therefore not a stylistic choice but arithmetic: the best either
Menu can do is three Recipes twice and one once, which is exactly what both now
do. A third Menu would repeat identically.

The four are also four variations on one idea — a sweetened yogurt or soft-cheese
base with fruit or chocolate folded through — which is why
[Per-Slot Macro Bands](06-per-slot-macro-bands.md) deliberately widened
pudding's range past what the sample could support. Growing the pool is what
lets that range be measured rather than guessed.

### The bar

`CLAUDE.md`'s Recipe bar, and pudding's Band from `GOALS.md`: **~12g protein,
~155 kcal**, range 10–20g / 100–250. The existing four sit in 11–13.5g /
120–170, so there is deliberate room above them.

Puddings carry **no `protein` field** — ratified in
[Extract The Corpus](07-extract-the-corpus.md).

### Done when

The pudding pool is large enough that a Menu can fill 7 nights without using
any Recipe more than twice, and the four Bands still hold when each Menu's days
are re-summed.
